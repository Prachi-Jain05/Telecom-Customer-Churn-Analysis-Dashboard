# 📊 Telecom Customer Churn Analysis

Project Overview
This project analyzes customer churn patterns in a telecom company using Power BI. The objective is to identify factors influencing customer churn and provide actionable recommendations to improve customer retention.

Tools Used
Power BI
Microsoft Excel
DAX (Data Analysis Expressions)

Dataset Information
Source: [Telco Customer Churn – Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)
Total Customers: 7,043
Total Churned Customers: 1,869
Churn Rate: 26.5%

Dashboard Features
Customer Profile Analysis
Churner Profile Analysis
Contract Type Analysis
Internet Service Analysis
Payment Method Analysis
Gender Distribution Analysis
Senior Citizen Analysis
Monthly Charges & Total Charges Comparison
Interactive Filters and Visualizations

Key Insights
Churn Rate stands at 26.5%.
Month-to-Month contract customers show the highest churn risk.
Churned customers have higher average monthly charges than retained customers.
Fiber Optic customers represent the largest customer segment.
Electronic Check users exhibit higher churn behavior.
Senior Citizens contribute significantly to overall churn.

Business Recommendations
Encourage customers to switch to long-term contracts.
Review pricing strategies for high-billing customers.
Improve retention initiatives for Fiber Optic users.
Promote automated payment methods.
Develop targeted loyalty programs for Senior Citizens.
